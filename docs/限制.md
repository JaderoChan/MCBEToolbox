# 限制

当前程序设计与实现存在如下限制：

1. 假定最低可用的游戏版本为 `1.21.50`（**苍园觉醒** 版本），使用低于此版本的游戏加载程序生成的包时，可能会出现方块 ID 不正确的问题。

    > 之所以使用这个版本，是因为在这个版本中，方块 ID 拆分工作几乎已经完成，这使得处理不同变种方块的逻辑更容易实现。

2. 假定指令与结构文件中使用相同的方块 ID。
3. 对于指令包，仅兼容新版本 `execute` 指令语法。
4. 仅使用 **各向同性**（6 个面纹理一致）或 **侧面相同**（不考虑顶底面情况如何，但 4 个侧面纹理一致）的方块。
5. 对于 **侧面相同** 的方块，仅按照竖直方向摆放。
6. 对于 **结构文件（.mcstructure）** 中的 `block_palette` 部分，仅填充 `name` 字段，不考虑 `states` 字段和 `block_position_data` 部分。

    > 在程序开发时测试版本（1.21.50）中，当 `states` 字段置空时，各类 **侧面相同** 的方块默认会以竖直方向摆放，在此假定未来不会发生更改。
    >
    > 如果要考虑 **侧面相同** 的方块的各种摆放方式与各类方块状态的话，实现起来不仅工作量巨大，也难以设计出合适的用户交互方式。所以此处不考虑上述字段的填充，让游戏使用默认值（在上面提及的版本中，**侧面相同** 方块的默认摆放方式正是竖直摆放）进行处理。
